# Fonsi Portfolio Hub

Personal portfolio site showcasing full-stack projects, AI agents, and SaaS demos.

- **Live:** [portfolio-hub-flax.vercel.app](https://portfolio-hub-flax.vercel.app)
- **GitHub Profile:** [@Fonsi44](https://github.com/Fonsi44)

## Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion

## Featured Projects

| Project | Description | Live |
|---------|-------------|------|
| Justicia-Verdadera | Legal SaaS with RAG, 2FA, penalty calculator | [pinedayasociadoshn.com](https://www.pinedayasociadoshn.com) |
| AI Document Agent | Chat agent with tool calling | [Demo](https://ai-document-agent.vercel.app) |
| SaaS Dashboard | Product-grade admin dashboard | [Demo](https://saas-dashboard-gules-chi.vercel.app) |

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
vercel --prod
```
